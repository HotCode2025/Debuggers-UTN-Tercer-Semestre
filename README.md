❗ **Reglas del repositorio⬇️**

   1. NADIE (sin excepción) puede realizar cambios dentro del repositorio si no es parte del grupo.
   2. Todos los cambios realizados deben ser aprobados por el Scrum Master de esa semana.
   3. Cada integrante puede realizar la tarea en el momento que crea conveniente, siempre y cuando los trabajos sean entregados a tiempo.
   4. Cada lenguaje tiene su carpeta y localizacion. Dentro de las mismas se encontrarán las tareas diarias propuestas encuadradas dentro de la carpeta correspondiente.
   5. Las tareas especiales tendrán su apartado especial dentro de cada lenguaje. 
   6. Los avances dentro del proyecto Final solamente se subirán si cumplen con el requisito de ser FUNCIONALES.
   7. Cada uno de los integrantes tendrá asignado semanalmente tareas de cada lenguaje.
   8. Antes de realizar una solicitud de `pull`, deberás hacer un `fetch origin` para sincronizar el repositorio online en tu repositorio local. 
   9. Cada commit realizado debera llevar:
```
- Titulo del commit igual que el trabajo realizado, en el mismo formato propuesto en las issues
  (Ej: 1.2.3 Titulo del trabajo).
- Descripcion del commit: Se deberá comentar brevemente que tarea se realizó, o que modificación se aplicó.
- Realizar el push para que pueda ser revisado por el Scrum Master, que podrá realizar el merge,
  modificar si hay algun defecto en el commit, o solicitar al integrante una revisión del codigo.

```
